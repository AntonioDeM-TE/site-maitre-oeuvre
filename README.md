# Atelier Horizon

Site vitrine responsive pour une agence de maîtrise d’œuvre :
- Direction artistique éditoriale et galerie photos
- Vidéo de présentation en arrière-plan
- Formulaire de contact prêt à connecter à Formspree, Netlify Forms ou un backend
- Lien Google Maps vers une adresse de démonstration : **12 rue des Architectes, 75008 Paris**

## Mise en ligne

Le site est statique : ouvrez `index.html` ou activez GitHub Pages dans **Settings → Pages**.

## Personnalisation

Remplacez les images Unsplash, la vidéo Coverr, les coordonnées et l’URL Google Maps dans `index.html`. Le formulaire est actuellement en mode démonstration côté navigateur ; ajoutez une URL `action` et retirez `event.preventDefault()` dans `script.js` pour le connecter à votre service d’envoi.
